# ML4DC-MuonPOG

A small per-lumisection anomaly study using the 10 one-dimensional `Muons/` monitoring elements in the DIALS `muo` workspace. The experiment uses 2025 `Muon0` PromptReco runs.

## Run

```bash
uv sync
bash runs/01_example.sh      # fetch one ME/run and plot the raw histograms
bash runs/02_all_2025.sh     # collect 2025 Muon0 data; resumable, but lengthy
bash runs/03_experiment.sh   # train the autoencoder and plot LS scores
```

The first DIALS query requests CERN authentication when needed. Run collection before the experiment on a fresh clone. The collector keeps all 2025 Muon0 processing versions except non-PromptReco 2025G tests; the experiment selects PromptReco only.

## Data and experiment

`data/run_labels.csv`, converted from the curated 2025 run note, is the **tracked input**: one row per PromptReco run (`run_number,label`). Its 744 runs comprise 727 provisional `good`, 8 `bad_well_known`, and 9 `bad_ambiguous`. The experiment checks that these runs match the DIALS-generated `data/runs.csv` before fitting. Labels describe whole runs, not individual LS.

`data/runs.csv` and `data/raw/` are generated by collection and ignored by Git. Each raw Parquet contains one dataset, run, and ME across its available LS. The 727 Good runs are split by run within each era: about 70% train, 15% validation, and 15% test. Both Bad groups join the test set. Only Good training LS fit the scaler and autoencoder; the fixed LS threshold is the **95th percentile** of Good validation LS scores.

The baseline uses two summaries from each ME (`log1p(entries)` and mean histogram position), giving 20 inputs to a 20→8→3→8→20 autoencoder. Its score is reconstruction mean-squared error. `results/scores.parquet` stores one row per LS with `split`, `label`, score, and threshold flag. `results/plots/` contains six era score plots, `all.png`, `test.png`, test-group LS score distributions, and the training/validation loss curve. `results/metrics.json` reports counts, losses, threshold, and descriptive flagged-LS fractions. No LS-level classification metrics are claimed because LS-level truth labels are unavailable.
